# Data

Datasets are **not** committed to this repo. This file lists where to get them and what each is used for.

## Synthetic data

Level 0 generates its own synthetic walking data with a script (`modules/00_python_tooling/project/generate_data.py`). No download needed.

## Public datasets

To be added as later modules are written. For each dataset, record:

- Name and link
- License and any usage restrictions
- Which module uses it
- Where to place it locally (inside `data/raw/`, which is gitignored)

## Team-collected data

Once WEAR starts collecting data from its own devices, document the storage location and access rules here. Never commit raw participant data.
