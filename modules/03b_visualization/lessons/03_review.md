# Session review and accessibility

A non-programmer should be able to locate events, see missingness, and compare channels without editing code. Prefer descriptive labels, units, a concise quality summary, and markers that do not depend on color alone. An offline review figure is the first deliverable; optional GUI controls can follow.

Review figures alongside the quality table. A flat sensor can mean stillness, a stuck sensor, or an incorrect conversion. Report evidence without assigning an unsupported diagnosis.

**Review checklist:** all channels visible, units stated, x-axis in seconds, gaps visible, event markers on every panel, quality counts available, output readable when saved.
