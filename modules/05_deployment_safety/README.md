# Level 5: Deployment and safety

**Status: written — synthetic-data training edition.**

## Prerequisites
Level 4 (or its checkpoint).

## Expected effort

Allow 45–75 minutes per lesson with its exercises, plus project, checkpoint,
and review time. See the [six-week plan](../../SIX_WEEK_PLAN.md) for pacing
and the artifacts to submit. The weekly plan includes both 3a and 3b.

## Work through this module

1. [Prediction and controller interfaces](lessons/01_interfaces.md)
2. [Freshness, bounds, and fault latching](lessons/02_watchdogs.md)
3. [Replay validation and team review](lessons/03_validation.md)

Then complete the [guided project](project/README.md) and [checkpoint](checkpoint/README.md).
All commands in task READMEs run from that task's directory. Install the root
`requirements.txt` first. Tests deliberately fail on starter code.

Data are synthetic; sensor ranges and thresholds are teaching assumptions,
not WEAR hardware specifications. Discuss actual hardware choices with the team.
